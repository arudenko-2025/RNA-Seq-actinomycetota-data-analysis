# Actinomycetota RNA-seq compendium for BGC expression analysis

This repository contains code and analysis workflows associated with our study of biosynthetic gene cluster (BGC) expression across a large Actinomycetota RNA-seq compendium. The dataset includes transcriptomes from 132 strains cultivated across multiple media conditions and was used to investigate medium-dependent BGC activation, expression patterns across gene cluster families, and gene co-expression networks associated with specialized metabolism.

The analyses in this repository include workflows for processing expression matrices, defining expressed BGCs, comparing BGC activation across media and cluster types, refining BGC boundaries using RNA-seq data, constructing strain-specific co-expression networks with iterative WGCNA, identifying BGC-enriched modules, and summarizing candidate regulators, transporters, and other genes co-expressed with BGCs.

This repository is intended to provide reproducible code for the main analyses and figures presented in the manuscript.
